# On-Premise Deployment Guide

Follow these steps to deploy the Saccoss Platform bare-metal on your server running Ubuntu 22.04 LTS or 24.04 LTS.

## 1. Prerequisites Installation

Connect to your server via SSH and install the required global dependencies:

```bash
# Update System Packages
sudo apt update && sudo apt upgrade -y

# Install Node.js (v20.x recommended)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs build-essential

# Install PM2 Process Manager
sudo npm install -g pm2

# Install NGINX
sudo apt install nginx -y

# Install MySQL Server
sudo apt install mysql-server -y
```

## 2. Database Configuration

Secure the MySQL installation and create the application database.

```bash
sudo mysql_secure_installation
```

Log into MySQL as root and run:

```sql
CREATE DATABASE kika_platform;
CREATE USER 'kika_admin'@'localhost' IDENTIFIED BY 'StrongPasswordHere!';
GRANT ALL PRIVILEGES ON kika_platform.* TO 'kika_admin'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

## 3. Application Setup

Clone the repository and install dependencies.

```bash
# Clone the repository
git clone https://github.com/YourOrg/KIKA.git /var/www/saccoss
cd /var/www/saccoss

# Install Node Modules
npm install
```

## 4. Environment Variables

Create a production `.env` file from the example.

```bash
cp .env.example .env
nano .env
```

Ensure you update the `DATABASE_HOST`, `DATABASE_USERNAME`, `DATABASE_PASSWORD`, and `DATABASE_NAME`. Remove or ignore Firebase-specific variables for the on-prem variant once the refactor is complete.

## 5. Database Migrations

Run TypeORM to construct the database schema. Ensure your `package.json` scripts accurately point to your un-compiled TypeScript TypeORM setup.

```bash
npm run schema:sync
```

*Note: If data seeding is required for the default on-premise admin user, ensure you run the user creation script after synchronization: `npm run create-user`.*

## 6. Build the Application

Compile the Next.js application for production.

```bash
npm run build
```

## 7. Start the Service using PM2

Launch the application to run continuously in the background.

```bash
pm2 start npm --name "saccoss-web" -- start
pm2 save
pm2 startup
```

*Follow the instructions generated by `pm2 startup` to execute the necessary systemctl daemon commands.*

## 8. NGINX Reverse Proxy

Create an NGINX configuration file to route traffic from port 80 to the internal Node.js process running on port 3000.

```bash
sudo nano /etc/nginx/sites-available/saccoss
```

Add the following configuration:

```nginx
server {
    listen 80;
    server_name my-internal-server.local; # Or IP Address

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

Enable the configuration:

```bash
sudo ln -s /etc/nginx/sites-available/saccoss /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

Access your application via the specified internal domain name or IP address!
